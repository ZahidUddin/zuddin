Senior Software Engineer · Mediusware Ltd

Hi, I'm Zahid Uddin — a backend engineer passionate about clean code and high-scale CMS architecture.

Over the past 8 years, I have built and maintained 18+ commercial websites and platforms for clients across the United States, Europe, and Asia. My expertise centers on translating complex business logic into clean, robust object-oriented PHP, custom Full Site Editing (FSE) themes, bespoke Gutenberg blocks with ACF Pro, and scalable REST APIs.

I reject the bloated "page-builder sprawl" common in traditional WordPress development. Instead, I write modular, zero-dependency code, optimize database indexes, configure Redis object caching, and fine-tune server stacks (PHP-FPM, OPcache, NGINX, Cloudflare) to deliver sub-second page loads and 95+ Core Web Vitals scores.
