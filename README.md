## 🚀 Overview

This website is an ultra-fast, zero-dependency, luxury editorial portfolio engineered for production. It features Satoshi + Chillax + Zodiak typography, a dual-theme color system (Dark Noir & Warm Champagne), interactive backend telemetry profilers, filterable project archives, and full WCAG accessibility.

## 💻 Local Preview & Deployment

### Local XAMPP Server:
Place this folder in your XAMPP web root (`c:/xampp/htdocs/zuddin/`) and visit:
```
http://localhost/zuddin/
```

### Static Hosting (Vercel / Netlify / GitHub Pages):
Because this is a completely static, optimized HTML5/CSS3/JavaScript codebase, simply push to GitHub and connect to Vercel, Netlify, or GitHub Pages. Zero serverless or node build configuration needed.
